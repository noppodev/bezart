Installation

Bezart DAWをインストールして使い始めましょう

システム要件

  • macOS 10.15 以降
  • Windows 10 以降
  • Linux (Ubuntu 18.04 以降)
  • 4GB以上のRAM
  • 2GB以上の空きディスク容量

ダウンロード

最新版のBezart DAWを公式サイトからダウンロードしてください。

ダウンロードページへ

インストール手順

  1. ダウンロードしたファイルを解凍します
  2. Bezart DAW.app（Mac）またはBezart DAW.exe（Windows）をダブルクリック
  3. インストーラーの指示に従ってインストールを完了させます
  4. アプリケーションを起動してライセンスに同意します
